# Calculator - The C# Academy
This project is part of [The C# Academy](https://thecsharpacademy.com).
This project is designed to introduce Object-Oriented Programming (OOP) in C# with ClassLib.

## Description
This is a calculator that allows you to perform basic calculations. This calculator keeps a history of your calculations

## Launch the project

### Prerequisites: Install .NET 10
- Go to the official [.NET website](https://dotnet.microsoft.com/download) and download the .NET 10 SDK.

### Clone the repo
- With URL
```bash
git clone https://github.com/Louis-dub/CodeReviews.Console.Calculator.git
```
- With SSH
```bash
git clone git@github.com:Louis-dub/CodeReviews.Console.Calculator.git
```

### Install dependencies
```bash
dotnet restore
```

### Launch the project
```bash
cd Calculator.Louis-dub
dotnet run
```

## Technologies used
- **C#**: To build the game logic and classes using OOP
- **.NET 10**: Framework used to develop the application
- **Spectre.Console**: To create a polished and interactive console interface

## What I learned
- Create a classLib in C#
- Connect a console and a classLib in C#
- How to use the Newtonsoft.Json package to save the data
